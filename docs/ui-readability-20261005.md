# 順位予想の答え合わせ：可読性の修正

## 変更

- 巨大な導入バナーを外し、年度・リーグ・暫定／確定・更新時点から一覧へ進む。
- 球団名・内訳16px、解説者名18px、補助情報14px（標準ルート16px時）。remで拡大し、文字を縮めて配置に押し込まない。
- 球団順位は開閉可能。スマートフォンは3列×2段。予想者の的中ランキングとは明確に区別。
- 閉じた行にも一致数、順位差合計、主な差分、出典リンクの有無を表示。「＋」を「予想の内訳を見る」に変更。
- 全順位一致だけを強調。並び順と同率処理を明記し、既存のポイント制は変更しない。
- 共有文にリーグ別の集計基準日時・暫定／更新遅延を保持。出典URLの存在を検証済みとは呼ばない。
- 検索・絞り込み・年度・リーグ・リンク共有・認証・登録・ロック・グループ・既存ポイントは維持。

## 検証の境界

このコミット作成前のローカル確認：純粋ロジック既存20＋表示ロジック11の計31ケースをNode runnerアダプタで実行し合格。通常のVitest/Next/Cloudflare全体テストとは区別する。

変更TSXからの静的レンダリングをChromiumで検査。架空データの390×844画面で先頭カードの上端約604px、名前18px、球団16px。320/390/1440pxと390pxのルート文字200%でページ全体の横はみ出しなし。内訳6行を確認。これはReact hydration、認証、サーバーDBの検証ではない。

前head e06b76a のCIはunit/build/dataゲート通過後、新規結果UIのE2E7ケースが失敗（run37260277645）。成功とは扱わない。固定2026-07-06のE2E順位fixtureは、実行時計によって未来判定または古いデータとなるため、同一INSERTのDB時刻に変更した。履歴・将来時刻・不完全snapshot・確定の検査は純粋ロジックテストに維持。実際の結果ロジックをテスト都合で緩めない。

更新E2E8ケースで、実データ経路の描画、検索・展開、共有失敗、年度／リーグ保持、320/390/1440px、文字200%を検査する。PRのCIではJSON結果・画像・失敗traceを7日間artifactに保存。最新headのCI結果はPRに記録する。失敗が残る間はdraftを維持する。

## 公開境界

マージ、本番デプロイ、実DB更新は実施しない。公開前には実サイトのデータ鮮度・公式順位・共有画像・canonical・サインイン状態を確認する。PV向上・初見ユーザー理解度は未計測であり、達成済みとしない。

復旧はこの可読性コミットのrevertで行える。DB migration・採点仕様変更はない。
