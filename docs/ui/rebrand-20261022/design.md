# 順位予想対決の名称統一とUI刷新

目的はファンが解説者の結果を見つけ、自分のXで話題にできること。旧版は可読性・保存・数字だけで合格とし、共有したくなる視覚的な階層が不足していた。
reframe: 色やロゴの差し替えだけでなく、結果を主役にする構造へ変更する。拡散率の改善は未測定で、公開後の計測対象。

対象オブジェクト: 年度、競技（現在はプロ野球）、リーグ、解説者、公開された予想、比較順位、出典。
主導線: 年度・リーグを選ぶ → 名前で探す → 内訳 → 画像保存／X共有。
SSOT: 既存season-resultsの集計値、source provenance。採点・母集団・公開保存の制約は変えない。
旧経路: 旧サービス名・旧共有カード描画を置換。URLとCloudflareのプロジェクト識別子は維持。

採用案: インク色とライム色、強い一致数、6球団の比較パネル。写真風の装飾や架空の称号は使わない。
代替案: ロゴのみ変更は目的不足。全面ダークは長い表の読解を落とすため、表は明るい面に残す。
合格条件: 新名称が主要ページ/メタ情報/共有画像に一貫。390px/1400pxで主要導線が操作でき横溢れなし。画像は実寸と縮小で名前と一致数が主役になり、全12球団・長い名前・暫定結果でも欠落や誤認を起こさない。独立レビューと公開後read-back。

## 確認と原因への対処

- 原因特定: 旧カードは情報を上から並べる描画で、合格条件が保存・数値・可読性に偏っていた。ブランド文字列も複数の描画/metadata経路に分散していた。
- 修正: 名前/一致数を主役にしたカードへ置換、6球団タイルと12球団比較を分けた。第一画面はインク/ライムで統一。スマホの説明文を省き結果への導線を優先した。
- 横展開: サイト、metadata、構造化データ、既存OG、画像保存、X/native共有文を同名称へ。faviconも更新。サイトURL・競技データ・集計方式は維持。
- 再発防止: 実ブラウザで名称・OG取得・共有文、長名の6/12球団PNG、320/390/1400幅を検証。新名称のscenarioをui-gate必須対象へ追加。CDN障害で新OGが壊れないよう既存同梱フォントを再利用。

390px初回検査は先頭成績が799.875pxで不合格。構成修正後745.09375px、横溢れ0（下ナビより上の780px以内）。閾値は変更していない。
275 unit testとCloudflare向けbuildは成功。画像は架空fixtureで通常・長名・6/12球団・不一致を目視し、独立レビューを実施する。公開後の共有率・流入・利益はこの検査では証明しない。

独立レビュー: 通常/長名の6・12球団、OG、1400px、最終390px（初見/展開/集計情報）、不一致4/6カードを実画素で確認し、追加blockingなし。視覚合格と外部効果は区別する。
UBS: staged JS 44 filesを検査。critical 2件は既存OG routeの64-65行の静的Promise.all（フォントと予想データの並列取得）をprototype pollutionとした誤検知。リクエスト由来キーのobject mergeはなく、当該差分はサービス名のみ。検出を抑制する変更は加えていない。
