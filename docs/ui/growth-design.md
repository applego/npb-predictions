# 結果から始める予想リーグ

問いは「誰が当てたか」「気になる解説者はどこを外したか」「その結果を友達に見せられるか」。
解説者のロック済み予想と、同時点の完全な6球団順位が表示の正本。検索・リーグ・年度・完全一致はURLに残す。
現行の投稿中心ホームを結果一覧へ置換し、予想登録・一般参加者・ポイント制は別の名詞として残す。
前回PR65を再利用し、二重の集計実装を増やさない。未公開PRと本番を混同しない。

結果一覧はスマホでは縦の比較行（名前→一致数→主な差→出典）、展開後は予想/実順位を表で照合する。
スポーツ紙の見出しと緑のスコア欄を使い、巨大な宣伝バナー・メダル絵文字・広告ポップアップを置かない。
幅320/390/1400pxと200%文字拡大を検証する。出典未登録・暫定・欠測・取得失敗を区別する。

Xはユーザー操作の投稿画面を用意し、来訪ユーザー本人が自分のアカウントで共有したくなる結果カード・文面を用意し、運営投稿は行わない。
収益は28日貢献利益（確定収益−返金−手数料−直接費）を主指標とする。
PV・クリック・PR件数は利益と数えない。既存MONETIZATION.mdは仮説として再評価し、初回実験を絞る。
