# 結果比較・共有画像の改良（2026-10-25）

ユーザーの目標は、解説者の予想を複数指標で比較し、その結果を共有できる公開サイト。
前の配色・巨大な見出しを最終案とは扱わない。今回はスポーツ記事の結果一覧に寄せた簡潔な構成を採用し、順位予想点・一致数・順位差を同時に読めるようにした。

## 変更と正本

- 既存scoring.tsの順位点（差0〜5に+5/+3/+1/−1/−3/−5）を使用。個人タイトル点は含めない。
- 指標切替はsort=points/exact/deviationに保存。同点は同順位。登録全体で採番してから同内容の表示をまとめ、検索で順位を繰り上げない。
- 予想・実順位・出典・確定状態・保存母集団は既存の検証済み保存データを維持する。人気/大穴の新しい採点は追加していない。
- 結果ページの重複する旧ナビを外し、スマホでも一覧へ早く到達する。画像は得点を主役に、指標別順位・一致数・球団別内訳・出典・集計日時を保持する。
- 新旧の画像生成経路を追加併存させず、既存ResultCardDownloadと共通OGを更新する。

## 原因と再発防止

1. 根本原因：一致数を既定の採点と見せ方に固定し、得点との比較・共有する指標の選択ができなかった。
2. 修復：共通rankResultEntriesによる指標別採番とURL復元、比較可能なカラム、同じ指標のPNG。
3. 横展開：一覧・検索・同内容集約・共有先URL・ダウンロード画像・共通OGへ反映。
4. 検証：一致数が多くても得点が低い反例、登録1/1/3の同順位維持、実ブラウザの3指標並びとURL復元、320/390/1400px、セ6球団/総合12球団の実PNGを確認。

実装後の関連テスト・CIと公開確認はPR80の証拠を正本とする。ローカル確認と公開確認を混同しない。
